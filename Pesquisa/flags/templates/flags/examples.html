Basic Flag Icons

Display flags using the {% templatetag openblock %} flag_icon {% templatetag closeblock %} template tag:

{% flag_icon 'BR' %} Brazil
{% flag_icon 'US' %} United States
{% flag_icon 'FR' %} France
{% flag_icon 'DE' %} Germany
{% flag_icon 'JP' %} Japan
{% flag_icon 'CN' %} China
{% templatetag openblock %} flag_icon 'BR' {% templatetag closeblock %} Brazil
{% templatetag openblock %} flag_icon 'US' {% templatetag closeblock %} United States
{% templatetag openblock %} flag_icon 'FR' {% templatetag closeblock %} France

Different Sizes

Flags can be displayed in different sizes:

{% flag_icon 'BR' size='16' %} 16px
{% flag_icon 'BR' size='24' %} 24px (default)
{% flag_icon 'BR' size='32' %} 32px
{% flag_icon 'BR' size='48' %} 48px
{% templatetag openblock %} flag_icon 'BR' size='16' {% templatetag closeblock %}
{% templatetag openblock %} flag_icon 'BR' size='24' {% templatetag closeblock %}
{% templatetag openblock %} flag_icon 'BR' size='32' {% templatetag closeblock %}
{% templatetag openblock %} flag_icon 'BR' size='48' {% templatetag closeblock %}

Custom Styling

Add custom CSS classes and styles:

{% flag_icon 'FR' size='32' style='border-radius: 50%; border: 2px solid #333;' %} Rounded with border
{% flag_icon 'DE' size='32' style='filter: grayscale(100%);' %} Grayscale filter
{% templatetag openblock %} flag_icon 'FR' size='32' style='border-radius: 50%; border: 2px solid #333;' {% templatetag closeblock %}
{% templatetag openblock %} flag_icon 'DE' size='32' style='filter: grayscale(100%);' {% templatetag closeblock %}

Flag Emoji Filter

Use the flag_emoji filter to display emoji flags:

{{ 'BR'|flag_emoji }} Brazil
{{ 'US'|flag_emoji }} United States
{{ 'JP'|flag_emoji }} Japan
{% templatetag openblock %}{% templatetag openblock %} 'BR'|flag_emoji {% templatetag closeblock %}{% templatetag closeblock %} Brazil
{% templatetag openblock %}{% templatetag openblock %} 'US'|flag_emoji {% templatetag closeblock %}{% templatetag closeblock %} United States
{% templatetag openblock %}{% templatetag openblock %} 'JP'|flag_emoji {% templatetag closeblock %}{% templatetag closeblock %} Japan

Country Selector

Use the country selector for forms:



{% country_selector name='country' css_class='country-selector' %}

Country List

Display a list of countries with flags:

{% country_flag_list limit=20 as countries %}
{% for country in countries %}
{% flag_icon country.code %} {{ country.name }}
{% endfor %}
{% templatetag openblock %} country_flag_list limit=20 as countries {% templatetag closeblock %}
{% templatetag openblock %} for country in countries {% templatetag closeblock %}
  {% templatetag openblock %} flag_icon country.code {% templatetag closeblock %} {% templatetag openblock %}{% templatetag openblock %} country.name {% templatetag closeblock %}{% templatetag closeblock %}
{% templatetag openblock %} endfor {% templatetag closeblock %}

Fallback Behavior

Flags gracefully fall back to emoji when CDN is unavailable:

{% flag_icon 'XX' %} Unknown country (shows default flag)
{% flag_icon 'ZZ' fallback_emoji=False %} No fallback (empty if CDN fails)
{% templatetag openblock %} flag_icon 'XX' {% templatetag closeblock %} Unknown country
{% templatetag openblock %} flag_icon 'ZZ' fallback_emoji=False {% templatetag closeblock %} No fallback
